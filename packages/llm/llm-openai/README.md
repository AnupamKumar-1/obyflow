# @obyflow/llm-openai

OpenAI adapter for [Obyflow](https://github.com/Obyflow/obyflow)'s AI-assisted investigation features, implementing the `LLMAdapter` interface from [`@obyflow/llm-core`](https://www.npmjs.com/package/@obyflow/llm-core).

This package is used internally by the [`obyflow`](https://www.npmjs.com/package/obyflow) CLI when you run:

```bash
npx obyflow config llm --provider openai
```

## Install

```bash
npm install @obyflow/llm-openai
```

Requires Node.js ≥ 22 and an `OPENAI_API_KEY`.
