# @obyflow/llm-ollama

Ollama adapter for [Obyflow](https://github.com/Obyflow/obyflow)'s AI-assisted investigation features, implementing the `LLMAdapter` interface from [`@obyflow/llm-core`](https://www.npmjs.com/package/@obyflow/llm-core). Use this to run investigations against a local model with no API key required.

This package is used internally by the [`obyflow`](https://www.npmjs.com/package/obyflow) CLI when you run:

```bash
npx obyflow config llm --provider ollama
```

## Install

```bash
npm install @obyflow/llm-ollama
```

Requires Node.js ≥ 22 and a running [Ollama](https://ollama.com) instance.
